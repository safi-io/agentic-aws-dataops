Agentic AWS DataOps

Validate orders from S3, investigate data quality failures, and review incidents together.

Open DagsterOpen incident dashboard

Try an existing batch

  1. In Dagster, open Jobs → orders_data_quality_job → Launchpad.
  2. Use the configuration below, then click Launch Run.
  3. A clean batch succeeds and writes to S3 Silver. A broken batch fails validation and creates an incident in the dashboard.
ops:
  bronze_orders:
    config:
      source_key: bronze/orders.csv
  silver_orders:
    config:
      source_key: bronze/orders.csv

For a broken batch, replace both source keys with bronze/high_nulls.csv or bronze/unexpected_column.csv.

For 1,100 rows, use bronze/mixed-tests/20261018T205950Z-2afc5252/clean_large.csv. The broken counterpart is bronze/mixed-tests/20261018T205950Z-2afc5252/late_invalid_amount.csv.

This is a shared workspace: teammates see the same incidents and changes. Jobs run one at a time on AWS. Automatic remediation starts only when the incident sensor is enabled; email notifications are disabled for this demo.

Code changes belong in the shared repository. An authorized maintainer can deploy an updated checkout using the repository's team deployment instructions.
